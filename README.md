## 📋 Description

Autostart_Manager is a graphical startup manager for Linux Mint 22.3 (Cinnamon). It gives you simple and practical control over what programs start automatically when your computer turns on, going beyond what Mint offers by default.

## 📖 How to Use

### Adding a Program to Autostart

1. Launch Autostart_Manager from your application menu or terminal.
2. Click the "Add" button or select "Add New Entry" from the menu.
3. Browse to the program executable you want to add (e.g., `/usr/bin/firefox`).
4. Optionally set a delay before the program starts.
5. Click "Save" to add the entry.

### Removing a Program from Autostart

1. Open Autostart_Manager.
2. Select the program you want to remove from the list.
3. Click the "Remove" button.
4. Confirm the removal when prompted.

### Disabling a Program Temporarily

1. Select the program in the list.
2. Click the "Disable" toggle or "Disable" button.
3. The program will not start until you enable it again.

## 🛠️ Advanced Options

### Using Systemd Services

Autostart_Manager can also manage systemd user services. This is useful for applications that run as services rather than regular desktop applications. To use this feature:

1. Select "Systemd Services" from the mode menu.
2. Browse available user services.
3. Enable or disable services as needed.

### Scheduling with Cron

For advanced users, Autostart_Manager can help schedule programs using cron. This allows you to run programs at specific times or intervals.
